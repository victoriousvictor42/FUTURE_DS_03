# College Event Feedback Analysis (FUTURE_DS_03)

## 📌 Overview

This project analyzes student feedback collected from various college events to evaluate **satisfaction levels, engagement, and areas of improvement**. By combining quantitative ratings with qualitative comments, the analysis provides actionable insights for improving future event planning and execution.

---

## 🎯 Objectives

* Assess student satisfaction with different types of events.
* Identify strengths (e.g., organization, venue, speaker quality).
* Highlight areas needing improvement (e.g., scheduling, activity variety, crowd management).
* Apply **data analysis and sentiment analysis** techniques to extract insights from structured and unstructured feedback.

---

## ⚙️ Tools & Technologies

* **Python** (pandas, seaborn, matplotlib)
* **NLP** (TextBlob/VADER for sentiment analysis)
* **Google Forms/CSV** (feedback collection)
* **Jupyter Notebook / Google Colab**

---

## 📊 Key Findings

* Most students rated events **positively**, especially workshops and cultural nights.
* **Speakers and venues** received high satisfaction scores.
* Engagement was higher in interactive events compared to lectures.
* Sentiment analysis of text feedback highlighted appreciation for **organization and fun atmosphere**, with improvement areas including **venue capacity, event scheduling, and variety**.

---

## ✅ Conclusion

Overall, the events were **successful and well-received**, but adjustments in **logistics, scheduling, and inclusivity of activities** can further enhance future participation and student satisfaction.

---

## 📂 Project Structure

* `Data Import & Cleaning` – Loading and preprocessing student feedback.
* `Exploratory Data Analysis (EDA)` – Visualizations of ratings and participation.
* `Sentiment Analysis` – Extracting insights from open-text feedback.
* `Conclusions & Recommendations` – Key takeaways for event organizers.
